# 训练复现说明

依据 11-06 答疑（@H 问题 1）：「**训练代码需要提供**」。本包随附完整训练源码
（`train.py` + `src/` + `configs/`），本文件说明交付权重的训练配方与复现步骤。

> 注：SSD 缓存文件（`data/cache/*.npy`）体积达数十 GB，不随包提交；
> 首次训练时由 `src/data/cache.py` 从官方图片目录自动重建（见下方第 2 步）。

---

## 一、交付模型

| 项 | 内容 |
|---|---|
| 模型 A | `checkpoints/exp051_s896_best.pth`（ConvNeXt-Small @896）|
| 模型 B | `checkpoints/exp054_t896_a05_best.pth`（ConvNeXt-Tiny @896）|
| 集成方式 | 两模型的**单图 logit 等权平均** → sigmoid |
| 推理分辨率 | 896 × 896（灰度复制 3 通道，ImageNet 归一化）|
| 后处理 | 患者平滑 λ=0.15（同一 Subject 下多 study 的确定性混合；单 study 患者退化为 λ=0）|

## 二、环境

```
Python 3.12 / PyTorch 2.10.0+cu128 / timm / OpenCV
训练：单卡（Ada 或 Ampere，≥24GB），bf16 混合精度
推理：fp16（T4 原生支持；bf16 在 Turing 上会退化为 fp32）
```

## 三、复现步骤

### 1. 准备数据

把官方训练集按如下结构放置（与官方提供的目录一致）：

```
<DATA_ROOT>/train/subject_xxx/study_xxx/*.jpg
<DATA_ROOT>/valid/subject_xxx/study_xxx/*.jpg
```

并把 `<DATA_ROOT>` 写入 `src/constants.py` 的 `DATA_ROOT`（或按该文件读取环境变量）。

### 2. 重建图像缓存（首次必需）

```bash
python tools/build_cache.py --split train --size 896 --workers 8
python tools/build_cache.py --split valid --size 896 --workers 8
```

### 3. 训练模型 A（ConvNeXt-Small @896，含蒸馏）

教师软标签由三个 896 模型（S@896 / T@896α0.5 / T@896α0.9）在**官方训练集**上
等权平均生成（教师权重不随包提交，见申报清单说明）。

```bash
python train.py --config configs/teach_s896_a09_aug.yaml --run-name exp051_s896
```

若已有教师软标签，可在配置中设置：

```yaml
train:
  distill_alpha: 0.9
  distill_probs: outputs/preds/teacher2_train_probs.npy
```

训练 12 轮，batch 8 + 梯度累积 4，AdamW，OneCycle，强增强（RandAugment 2 ops、
RandomResizedCrop 0.65–1.0、旋转 ±10°、ColorJitter、RandomErasing p=0.35）。

### 4. 训练模型 B（ConvNeXt-Tiny @896，α=0.5）

```bash
python train.py --config configs/teach_t896_a05_aug.yaml --run-name exp054_t896_a05
```

### 5. 生成提交 CSV

```bash
python cost.py --members members.json --from-split test --submission \
    --fast-decode --patient-lambda 0.15 --out submission.csv
```

包内 `submission.csv` 即由上一条命令在官方测试集上直接产出（同一份代码、
同一预处理、同一聚合口径），因此与 `cost.py` 的输出天然一致。

### 6. 核验耗时

```bash
python cost.py --members members.json \
    --pictures <官方 pictures_100 目录> \
    --warmup  <官方 pictures_5 目录> \
    --out check.csv --rounds 3 --fast-decode --patient-lambda 0.15
```

官方口径下（Xeon 8352V + vGPU，GPU 空闲）本包实测 **56–71 ms/study**。

## 四、关键实现选择（与耗时相关）

| 选择 | 理由 |
|---|---|
| GPU 解码（nvJPEG） | 慢 CPU 服务器上比 cv2 快约 20% |
| GPU 缩放 + 归一化 | 省去 CPU 上的 `cv2.resize`（服务器上约 19ms/图）|
| 单 study 串行、study 内多图并行 | 官方要求 batch=1 以 study 为单位，**不允许跨 study 预取** |
| fp16 推理 | T4 原生 tensor core；bf16 在 Turing 上退化 |
| 患者平滑耗时计入 | 按 11-06 答疑要求，聚合耗时已实测并摊入每 study 均值 |

## 五、随机性

- 训练 seed 固定（A: 42，B: 108），但不同 GPU/驱动下浮点累加顺序不同，
  重训结果不会逐位一致。
- 提交 CSV 由**冻结权重**确定性推理生成；`cost.py` 在同类 GPU 上的复现误差
  远小于官方 4 位小数比对口径。
